# Expo 自助演示

用户预计 2026-11-16 下午 Expo 时可能不在场，要求把引导和讲解融入演示，让评委能自行体验。

## 入口与路线

以 `/?demo=1` 进入完整本地预制案例，首先看到纸箱教练欢迎说明、主理人场景与约三分钟的五站路线。已有 `?demo=1&page=report` 等页面直达入口也会显示欢迎和开始按钮。点击开始回到办公室并播放协作回放；不强制看完，可以直接继续。

1. 团队协作：42 秒字幕跟随识别、需求/竞品、利润、风险、汇总阶段，解释各角色要回答的问题。办公室保持分析页主体。
2. 结论与证据：阅读首批 120 件试销结论，一键展开需求维度和 H1 六个月原始历史。
3. 动手测算：一键设置 CVR 6%，从基准 $4.70/件变为 $0.70/件；也可自行改参数。讲解引用当前计算结果；离开本步向后继续时恢复基准，避免把试算与原案例报告混读。
4. 追问教练：自动引用利润判断发起本地预制对话，或自行选文与连续提问。
5. 带走方法：提供 N2、N3 本地小题，支持提示、作答、错误反馈、重试、跳过与下载学习回顾。本题成绩不当作能力认证。

每站同时解释操作、观察点及产品价值。页面底部与顶部都可继续路线。随时自由浏览、跳站、恢复导览；体验回顾只标记实际展开证据、重算、成功对话和提交过答案的操作，不因点击下一步冒充完成。

## 下一位访客

顶部与回顾页都有“下一位体验 / 从头开始”。重置案例参数、对话、题目、草稿、展开状态、导览与回放，回到欢迎页。刷新也重新载入基准案例。不自动定时重置，避免清掉正在体验的内容。

## 模式边界

全部演示操作走浏览器 demoProvider，不调用真实模型、数据源或付费服务，不写入真实研究历史。完整实时分析仍可从模式切换进入；界面持续标注虚构案例、模拟核验和协作回放。当前演示的迁移评分等模型操作不作为主要体验入口，实时模式原有流程不变。
