# Pickwise 分析过程与报告的信息层级

日期：2026-11-16

## 已确认的设计约束

用户明确纠正：办公室始终是分析过程页的主体，这一点不变。后续整理信息结构时，不把办公室缩成辅助侧栏、卡片或默认折叠内容。沿用已确认的奶油色、森林绿、鼠尾草绿与暖金配色，保留人物、工位、动画及本地模拟回放。

## 本次调整

- 过程页：办公室处于首要大列；右侧集中实际进度和六步导航；下方展示所选步骤。窄屏先展示完整办公室，再显示进度、步骤与依据。
- 步骤正文：默认显示查到的结果、图表和解读；分析方法、常见误读、证据边界与教学说明放在同一步骤的可展开区域，不再复制到另一列。
- 点击步骤后打开相应内容并定位详情；每一步教学展开状态分别保留。
- 报告页：初筛结论 → 五维判断 → 下一步验证 → 完整报告与下载。证据与数字解读按维度展开，缺口保持可见。
- 旧版报告在结论前提示过期；未完成任务提供返回进度的入口。研究处理数量包含已执行但待核实的步骤，同时显示待关注事项，避免把已处理等同于已验证。
- 打印前临时展开五维证据、术语与关键假设，打印后恢复阅读状态。
