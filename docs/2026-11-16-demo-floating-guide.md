# 固定导览浮层与自助讲解开关

用户要求导览滚动时始终可见，并可在本人做 pitch 时一键关闭自助讲解，恢复原来的演示模式。功能仅在演示模式出现。

- 进行中的五站导览改为页面左下方固定浮层，保留当前步骤、操作与下一步。讲解内容可独立滚动，下一步按钮固定在面板底部；可收起为精简状态。自由探索时保留一个小型恢复入口。
- 顶部提供“自助讲解”开关。关闭后隐藏产品介绍、收费 pitch、导览及相关入口，显示原本的办公室、报告、证据与学习页面；模拟数据、测算、练习、对话及导览进度不因开关而重置。
- 开关偏好保存在当前浏览器 `pickwise.demo-assistance`，刷新和“下一位体验”不会擅自重新开启。重新打开继续保留的导览；“下一位体验”仍负责恢复案例基准。
- 箱子教练打开时，导览自动采用精简状态。窄屏下聊天侧栏为底部导览留出空间，发送区与导览按钮分别可用；关闭聊天恢复原展开状态。
- 原页面底部的重复导览按钮已由固定浮层取代。页面底部留出滚动余量，便于查看被面板暂时覆盖的内容。打印不包含开关与浮层。

浏览器验证：滚动从约 175px 到 1239px，浮层边界坐标保持一致且计算样式为 fixed；桌面与 390px 下检查聊天输入、导览面板互不重叠。关闭后刷新仍为普通演示报告，不显示 pitch 或导览。回归覆盖折叠、重新展开、开关持久化、恢复进度、测算保留与实时模式隔离。
