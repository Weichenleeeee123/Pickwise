# 浏览器历史与会话隔离

用户要求：访问历史在当前浏览器持久保存。执行采用设计、实施计划和测试驱动流程；本次直接在已授权的数据管理范围内完成。

方案：localStorage 保存随机浏览器凭据和紧凑历史摘要，只有该浏览器创建/访问且获授权的任务才写入列表。列表不再请求服务器全量会话。实时分析与原始证据继续留在服务端以支持后台任务；服务器只保存浏览器凭据的 SHA-256 摘要，读取、修改、导出和缓存复用均限定相同所属浏览器。旧的无所属任务保留在服务器，不自动认领或公开。

不增加账号登录、跨设备同步、删除历史/文件或数据库重构。演示案例不写入真实历史。存储被禁用或容量不足时保留内存回退，并明确提示刷新后可能丢失历史。主域名和 www 统一到主域名，避免两个 origin 形成两份本地数据。

验收：浏览器刷新和重启保留列表；空白浏览器列表为空；第二浏览器即使知道 ID 也不能读取、修改、导出其他任务；损坏 localStorage 不导致白屏；现有测试全部通过；部署后验证 HTTPS、演示、前后端资源和隔离行为。保持其他未提交 UI 工作，发布包仅叠加本任务文件到上一线上版本。
