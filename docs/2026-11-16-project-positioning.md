# Pickwise 项目定位与表达口径

日期：2026-11-16\
来源：用户在 Expo 与路演准备阶段明确对齐的产品定位。\
适用范围：项目介绍、Expo 讲解、路演 PPT、讲稿、产品演示和宣传文案。

## 一句话介绍

Pickwise 是为电商 OPC 打造的 AI 选品教练：作为数字员工完成选品研究与分析，并在真实分析过程和结果中讲清数据与判断依据，帮助新手主理人在一次次选品中学会判断商品价值。

## 定位层级

| 层级 | 统一定义 |
|---|---|
| 产品本质 | 电商选品 Agent |
| 岗位价值 | 给电商 OPC 做选品的数字员工，承担实际研究、分析计算和成果交付 |
| 差异化能力 | 将教学嵌入同一次选品分析的过程与结果 |
| 对外产品身份 | AI 选品教练 |
| 首要用户 | 需要选品支持、同时缺少判断经验的新手电商 OPC 主理人 |
| 当次使用价值 | 完成一个候选商品的研究与评估，形成有依据的判断及下一步建议 |
| 持续使用价值 | 通过反复选品，逐步理解哪些数据值得看、为什么看、怎样判断商品价值 |

## 两项同时成立的产品能力

**选品 Agent 能力。** 自主完成商品识别、需求研究、竞品比较、利润与资金分析、风险核验和报告交付。以真实可得证据和用户输入支持判断，明确数据缺口。教学环节不阻塞正常任务执行，用户跳过练习仍可获得研究成果。

**嵌入式教学能力。** 在当前商品的真实分析中解释查什么、为什么查、数据怎么读、结论怎样形成。结果页通过依据说明、参数调整、学习记录和迁移练习，帮助用户把本次分析的方法带到下一次选品。

这两项能力共同构成“选品教练”。对外介绍应同时说明工作交付和教学价值，避免只讲课程、辅导或练习，遗漏数字员工完成工作的基础能力。

## Expo 与路演的讲述顺序

1. 先介绍用户与岗位：新手电商 OPC 主理人需要一名能承担选品研究的数字员工。
2. 展示实际工作闭环：给出候选商品，Agent 调研、核对证据、比较、计算并交付分析。
3. 在同一次演示中指出教学：为何查这个数据、这个数字怎么读、为什么形成这个判断。
4. 用参数调整或另一个商品练习展示方法迁移机制，说明持续使用的学习价值。
5. 总结双重价值：当前这次选品有工作成果，主理人的判断方法也能在使用中得到训练。

## 简短口头介绍

我们做的是给电商 OPC 用的选品 Agent，相当于一名选品数字员工。它能自主查数据、研究竞品、算成本，完成一次商品分析。在这套工作能力上，我们把教学嵌进过程和结果，让新手主理人看懂该看哪些数据、为什么这么判断。主理人完成一次次选品，也逐渐积累判断商品价值的方法，所以我们把它叫作 AI 选品教练。

## 对现有材料的修正依据

- 数字员工的选品工作能力应先于教学机制得到清晰介绍。
- “能识别证据不足”属于可信分析的质量要求，不能单独承担全部产品价值叙事。
- 候选商品分析、分析报告和成本计算是实际工作交付，不能只包装成教学素材。
- “让用户逐渐学会判断”是产品目标；练习机制已实现与真实学习成效已验证需要区分。
- 项目定位面向电商 OPC，当前首版支持 Amazon 美国站候选商品分析；定位对齐不自动扩大已实现范围。
