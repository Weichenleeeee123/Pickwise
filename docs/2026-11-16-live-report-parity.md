# 真实分析与演示报告的结构统一

用户要求真实 Agent 分析能生成与完整演示相同层级的报告，且给出当前可执行的结论。

## 改动

`server/report.js` 统一从当前证据、程序计算与经营输入生成版本化报告：当前推进建议、成本与资金摘要、已取得证据范围、五维引用与执行计划。模型负责解释，程序保证必需结构。模型输出不合格时也使用本次证据生成报告，不退回没有引用的通用五维文字。

建议分为停止、暂缓、打样核价和首批试销。首批建议需要连续需求、独立可比竞品、正贡献、预算覆盖与有效数量；缺个人成本和预算时不给首批数量或完整利润。召回标识符匹配会优先要求核对型号批次。风险状态与下单前核验保留，不伪装为合规放行。

界面与 Markdown 共用相同结构和数字。经营输入改变时，已生成报告保留原快照并标为陈旧；运行中再次改成本会排队重算，不能把新参数的哈希写入旧文字。旧式报告在输入未改变时可以补齐展示结构，不覆盖存储的历史结果。

目标类目榜单中的真实商品价格、标题与评分进入候选池，保留来源与观察时间，不补造父体、规格、销量或 BSR。已存在的完整商品详情优先，较新的榜单候选快照可追加历史。真实周级销量估算可以显示在分析图表中，明确保留来源周期，不转换成月订单。
